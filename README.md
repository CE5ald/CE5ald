## Featured projects

### [Companion Deck](https://github.com/CE5ald/companion-deck)

[![The home screen: now playing with cover art, CPU, GPU and RAM dials, and the audio mixer.](https://raw.githubusercontent.com/CE5ald/companion-deck/main/docs/images/home.png)](https://github.com/CE5ald/companion-deck)

Turns an old Android tablet into a touch control surface for a Windows PC: now-playing with artwork, a per-app volume mixer, live CPU/GPU/RAM gauges, a game and app launcher, and a soundboard that can play into a voice call.

Built with Kotlin, C# / .NET 8, JavaScript, WebView, WASAPI, NAudio, adb.

The full list, with details, is on the [CV site](https://ce5ald.github.io/#projects).
