### [Companion Deck](https://github.com/CE5ald/companion-deck)

[![The home screen with now playing, CPU, GPU and RAM dials, and the audio mixer.](https://raw.githubusercontent.com/CE5ald/companion-deck/main/docs/images/home.png)](https://github.com/CE5ald/companion-deck)

Turns an Android tablet into a touch control surface for a Windows PC: now-playing with artwork, a per-app volume mixer, live temperatures and frame rate, a game and app launcher, a soundboard, and calendars.

Built with C# / .NET 8, Kotlin, JavaScript, WASAPI, Windows ETW, adb.
